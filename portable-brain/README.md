# Portable Brain (Refreshed Universal AI Skill & Context Vault)

> Path-independent, zero-secret, zero-PII knowledge & skill vault merged from Central Brain universal skills (`12` powerhouses), universal operating rules, UI glassmorphism/anti-slop standards, and external coding harness instructions.

## Quick Start

```bash
# List or search all 12 universal skills
python portable-brain/brain_cli.py info
python portable-brain/brain_cli.py select "cloud gpu" --universal
```
