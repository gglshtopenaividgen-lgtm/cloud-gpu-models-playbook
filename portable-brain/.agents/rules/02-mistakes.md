# Mistakes & Failure Logs

Before attempting to debug a persistent issue:
1. Review universal anti-patterns below and in `<BRAIN_ROOT>\mistakes.md`.
2. Review the target project's own `context/mistakes.md` as mapped in `project_map.md`.

Do not guess the solution; read the past failure logs first.

- **Google Flow Image Extraction**: Never search for  lob: or googleusercontent to find generated images in the new UI. Always search for media.getMediaUrlRedirect. Furthermore, when extracting multiple images in sequence, ensure the UUID in the src URL changes to avoid capturing the previous image.
- **React contenteditable**: Setting .innerText via JS does not enable submit buttons. Always use simulated keystrokes (page.keyboard.type) to trigger React state.
- **DeepCoder / DeepInvestigator 1-Second Subagent Crash**: In Antigravity's `language_server.exe`, built-in subagents `DeepCoder` and `DeepInvestigator` require the missing tool `skill_search`, causing them to fail initialization immediately (`failed to construct executor: failed to resolve components: unknown component: tool "skill_search" not found in registry`) and terminate after 1 second ("Worked for 1s"). NEVER invoke `DeepCoder` or `DeepInvestigator`. For coding, always invoke `TypeName='self'` (or `TypeName='research'` for read-only exploration, or custom agents via `define_subagent`).
- **Central Brain Preservation (Strict Anti-Wipe Rule)**: Single-project agents must NEVER overwrite or wipe files in `<BRAIN_ROOT>` using destructive write tools (`Overwrite=true`). ALWAYS read first, merge, and append project sections. Commit all brain changes to Git.
- **Implementation Side-Effect Regressions (Zero-Breakage Mandate)**: When implementing a feature or fixing an issue, NEVER touch adjacent working features without regression testing. In past sessions, agents broke working portal logins, disabled music playback, and broke mobile docks while attempting to fix unrelated items. Run regression tests before declaring work done.
- **Zero-Mock Data Invariant**: Never replace authentic upstream APIs with hardcoded fake mock records or placeholder stubs (e.g. fake University-Portal profiles or simulated music tracks) when transient network errors occur. Provide honest error states and actionable diagnostics.
- **Premature '100% Complete' Declarations**: NEVER proclaim a task complete or tell the user "everything is verified and working" without actually booting the runtime, verifying listening ports, testing end-to-end user flows in the browser/CLI, and checking console logs for uncaught exceptions.
- **Tool Loop Fumbling Under Frustration**: When a user reports that a feature is broken or expresses frustration, NEVER enter repetitive MCP tool loops (refreshing `about:blank`, repeating netstat commands, taking duplicate screenshots). Immediately inspect the core application source code, trace data flow, and fix the defect.
- **Touch Gesture Conflict on Vertical/Horizontal Sliders**: Never bind horizontal/vertical swipe gestures to top-level containers without isolating touch events (`e.stopPropagation()`) on sliders, EQ knobs, and scrubber bars. Unisolated events cause adjusting an EQ or scrubbing song duration to inadvertently trigger track changes.
- **HTML5 Audio MEDIA_ERR_ABORTED False Positives**: `target.error?.code === 1` occurs naturally when aborting previous tracks, seeking, or scrubbing. Never trigger automatic track skipping on error code 1, or it causes cascading queue skips until playback stops.
- **Mobile PWA AudioContext & User Activation Loss**: Asynchronous IndexedDB checks before `audio.play()` break the browser's transient user activation flag. Always invoke `AudioEngine.unlock()` and `audio.play()` synchronously in the user touch/click handler.
- **Private Data Leaks in Database Queries**: Always filter database queries by `userId = currentUserId` and enforce document-level read/write permissions (`Role.user(userId)`). Never allow personal playlists, documents, or credentials to be served universally to unauthenticated/guest users.
- **Cloud GPU Credit Zero-Waste Rule**: NEVER instruct the user to launch an active cloud GPU instance (Modal A100, Colab, RunPod) until ALL client scripts, payload JSON files, and save directories are 100% written, syntax checked (`node --check`, `python -m py_compile`), and pre-verified.
- **Cloudflare Edge 30s Timeout (HTTP 524 / 1102)**: Cloudflare Workers terminate at 30 seconds. NEVER dispatch `fetch()` calls to external VMs or slow AI providers without an `AbortController` (max 25s timeout) to catch timeouts gracefully before the edge isolate terminates.
- **Client Library SSR Execution Crashes**: Heavy client-only visualization or AST libraries (`@xyflow/react`, Babel standalone, canvas engines) attempt to execute DOM `window` methods during server SSR, crashing edge workers. Always wrap in `next/dynamic(..., { ssr: false })` or client-mounted guards.
- **Mineserver Milestone Snapshot Immutability**: Files in `ver_backup/` are strictly immutable historical archives. Automated backups must save exclusively to `latest_world/fortress_world.tar.gz`.
- **Kaggle Disk Quotas & Socket Reclamation**: In Kaggle, save models exclusively to `/tmp/models/` (57GB+) instead of `/kaggle/working/` (19.5GB limit). Reclaim in-process background Uvicorn sockets via `os.close(conn.fd)` on ports 8080/8081 before rebinding.
- **Git Historical Audit Invariant (Check Past Commits First)**: When an existing feature breaks or regresses after being operational, NEVER make blind forward patches or speculative multi-file refactors. Run `git log -p -n 10 <file>` or `git diff <commit>..<commit> <file>` to inspect the known-working state from 20-30 commits prior. Revert or port the verified logic.
- **Subsystem Blast Radius Isolation**: Developing or repairing localized sub-features (e.g. portal login, quickstore, audio DSP) must NEVER modify root layouts (`RootLayout.tsx`), core middleware (`middleware.ts`), or unrelated core functional modes (`ChatShell.tsx`, `Editor.tsx`).
- **Chrome Automation Stealth & Lock Hygiene**: Always use C++ level CDP stealth (Patchright) and attach to dedicated persistent user profiles. Never launch Chrome in Guest mode when account authentication is needed. Always kill orphan Chrome PIDs and release `SingletonLock` / `SingletonCookie` before launching automated sessions.
- **Zero-Subrequest Fast Cookie Middleware**: Never execute remote database queries (`await supabase.auth.getUser()`) inside edge middleware for API routes. API routes must handle internal authentication independently to prevent Cloudflare Worker Error 1102.
- **Mandatory `wrangler.jsonc` in CI/CD**: Cloudflare deployments must run `npx wrangler deploy --config wrangler.jsonc` so that `.open-next/assets` are bound and uploaded to Cloudflare's static edge CDN (`binding: "ASSETS"`), preventing static chunk requests from exhausting worker CPU limits.
- **Vite Build Without TypeScript Typechecking (`tsc -b`)**: Running `vite build` alone does NOT perform typechecking or validate identifier bindings; undeclared variables in React JSX (such as `playlists` passed as a prop without being destructured from a Zustand hook) bundle silently into production and cause runtime `ReferenceError` crashes in the browser error boundary. ALWAYS configure `"build": "tsc -b && vite build"` in `package.json` and run `tsc -b` to guarantee zero compile-time and runtime reference errors before pushing or deploying.
- **Ephemeral Cloud Notebook Silent Subprocess Anti-Pattern**: Spawning backend servers or workers as unpiped background subprocesses in Kaggle/Colab notebooks swallows critical startup tracebacks, model initialization crashes, and OOM exceptions, leaving the user staring at a frozen cell or generic failure. ALWAYS run services in-process (or with real-time stdout streaming) and execute sequential diagnostic verification steps ([1/8] through [8/8]) with explicit sys.stdout flushing and actionable diagnostic boxes upon any failure.
- **Audio Scrubber State Contention & Top-Level Gesture Collisions**: Dragging audio scrubbers / dials will fight HTML5 `<audio>`'s frequent `timeupdate` events unless `isScrubbing(true)` is explicitly dispatched to lock store updates during pointer dragging. Furthermore, top-level touch/swipe handlers on full-screen containers capture horizontal drags across scrubbers and slider tracks; swipe actions must be strictly isolated to specific artwork/visual boundaries with high minimum thresholds ($\ge 70\text{px}$) and $1.5\times$ horizontal axis dominance.
- **Mobile Multi-Band EQ Stacking & Ergonomic Touch Targets**: In mobile viewports ($\le 375\text{px}$), stacking 10 vertical faders side-by-side violates the $44\text{px}$ minimum touch target standard and creates visual crowding. Merge equalizers and spectrum visualizers into an interactive SVG curve with $44\text{px}$ touch envelopes (`r=22`), a horizontal frequency pill selector strip, and a single high-precision master touch fader.
- **Kaggle Ephemeral Pip NumPy Upgrade Trap**: When dynamically installing missing packages (e.g. gptqmodel, autowq) via pip in Kaggle notebooks, pip's dependency resolver will aggressively upgrade NumPy to 2.x, causing fatal binary breakages (ImportError with _center from numpy._core.umath) in pre-compiled scipy/sklearn C-extensions. Always explicitly pin numpy<2.0.0 in all pip install commands executed inside the notebook.
- **PowerShell UTF-16 BOM and Shell Redirection Trap**: In Windows PowerShell, piping text into files via >> or Out-File writes UTF-16LE with null bytes (\x00) by default, creating corrupt files that fail in Linux pip with Invalid requirement null byte errors. Furthermore, running os.system with unquoted package specifiers like numpy<2.0.0 triggers /bin/sh stdin redirection (cannot open 2.0.0: No such file). ALWAYS write files in explicit UTF-8 and invoke pip via subprocess.run([sys.executable, '-m', 'pip', 'install', *args]) to bypass shell parsing.
- **GGUF Download URL & Magic Byte Verification Trap**: When downloading quantized GGUF models from Hugging Face in automated scripts, an invalid repository slug or filename results in an HTTP 404 HTML error page. If downloaded via unflagged curl or naive streams, this HTML text is saved to the `.gguf` file, which later crashes `llama-server` with `invalid magic characters: 'Repo', expected 'GGUF'`. ALWAYS verify Hugging Face URLs via HEAD requests before hardcoding, enforce `curl -f -L`, and validate GGUF files by asserting `file.read(4) == b'GGUF'` and size > 100MB, automatically purging invalid/corrupt cached files.
- **Python Embedded Multiline String JS Newline Syntax Trap**: In single-file Python servers with embedded HTML/JS templates (e.g. `HTML_PAGE = """..."""`), raw newline escapes like `val.split("\n")` inside JavaScript are evaluated by Python into literal newline bytes (0x0A) across string quotes (`val.split("` \n `")`). Browsers immediately reject the entire `<script>` at parse time with `Uncaught SyntaxError: Invalid or unexpected token`, silently killing all click and form submission handlers (e.g., login buttons do nothing when clicked). ALWAYS use `String.fromCharCode(10)` or regex `/\r?\n/` instead of `"\n"` inside embedded JS string literals, and verify client code with `node --check` on the evaluated string before deployment.
- **Hugging Face Repository Slug Verification & Fallback Mirrors**: Never hardcode Hugging Face repositories or filenames based on quantizer naming assumptions (e.g. assuming `bartowski` quantized base 70B abliterated or Gemma 27B). Querying invalid repos returns `HTTP 401/404`, causing `RepositoryNotFoundError` on Kaggle/Colab. ALWAYS verify HF repos and files via live HEAD requests before hardcoding, validate GGUF magic bytes (`file.read(4) == b'GGUF'`), and configure multi-repo fallback mirrors (`fallback_repo`/`fallback_filename`) in `get_model_path()` to ensure resilient automated downloads.
- **Kaggle Persona Biometric Ban Evasion & Duplicate Account Invariant**: When an account is banned and its appeal rejected, the user's facial biometric template is permanently blacklisted in Persona (`identity-verification-provider`) / Kaggle Trust & Safety. Attempting Persona verification on ANY secondary or future account using the same face triggers an immediate `BAN_EVASION` match, causing Kaggle to instantly terminate the new account on sight. NEVER attempt Persona verification on a new account using a previously banned face. The current account is phone-verified (SMS) and runs 30h/week Dual-T4 GPU inference safely with ZERO Persona involvement. Never suggest using the previous banned account. TPU can only ever be unlocked with a clean, unverified 3rd-party face (e.g. family member).
- **Global Config Skills Bloat & Multi-Root Discovery Anti-Pattern**: Antigravity automatically scans and injects all skills from `~/.gemini/config/skills/`, `<workspace>/.agents/skills/`, and built-in roots into the system prompt on EVERY turn. Dumping fragmented micro-skills (e.g. 10 individual Cloudflare tools, 4 individual file format tools) or duplicating brain skills in `~/.gemini/config/skills/` floods prompt token budgets and causes confusion with native MCP tools. ALWAYS enforce **Branching Hub Architecture (Progressive Disclosure)**: consolidate capabilities into single master hub skills (e.g., `cloudflare`, `document-forge`, `ui-design-engine`) with sub-guides in `references/`, and keep `~/.gemini/config/skills/` deduplicated against Central Brain.
- **YAML Frontmatter Unquoted Colon Skill Invalidation**: In `SKILL.md` YAML frontmatter, any `description:` containing a colon followed by a space (e.g., `powerhouse: convert` or `engine: dynamic`) causes YAML parsers to fail (`mapping values are not allowed here`). Antigravity's runtime (`language_server.exe`) silently discards any skill whose frontmatter fails to parse, causing skills (like `document-forge` or `ui-design-engine`) to disappear from the agent prompt while remaining on disk. ALWAYS wrap YAML string descriptions in double quotes (`description: "..."`) and test via `yaml.safe_load()`.
- **Android Chromium HTMLMediaElement.fastSeek Remote Stream Collapse**: In Android Chromium / WebView, calling `HTMLMediaElement.fastSeek(targetTime)` on remote HTTP/cloud audio streams lacking keyframe index tables fails silently and resets playback to 0:00 (beginning of song). ALWAYS use direct `active.currentTime = clamped;` and guard `timeupdate` listeners with `!target.seeking` and `!engine.isRecentSeek(600)` to eliminate seek-collapse and stuttering during playback.
- **IndexedDB ObjectStore KeyPath Trap on Offline Caching**: When an IDB ObjectStore is defined with `{ keyPath: '$id' }`, storing a song record where `$id` is undefined throws an uncaught `DataError: Evaluating the object store's key path did not yield a value`, aborting the database transaction before offline broadcast notifications can fire. ALWAYS ensure reliable key fallbacks (`song.$id = song.$id || song.fileId || song.id || ...`) before executing IDB write transactions.
- **Waveform Scrubber Touch Bubbling & Album Cover Gesture Collisions**: Touch gestures on interactive scrubber bars bubble up to parent full-screen swipe listeners, causing accidental track skips when dragging playback position dials. ALWAYS dispatch `e.stopPropagation()` on `onTouchStart`, `onTouchMove`, and `onTouchEnd` in scrubber components, and restrict swipe listeners strictly to the album cover container with high horizontal thresholds ($\ge 95\text{px}$) and strict axis dominance ratios ($2.2\times$).
- **Native Search Tool Defaulting & Deep Research Neglect**: LLMs exhibit strong behavioral bias toward registered native tools (`search_web`) over executing shell scripts, leading agents to run shallow 1-hop Google queries even when the user explicitly commands a "deep search", "deep research", "comprehensive analysis", or "exhaustive comparison". Furthermore, failing to acquire profile leases leads to profile collisions on `Profile 14`. When deep search or research is requested, agents MUST NEVER call native `search_web`. They MUST execute Argon Deep Research (`search_engine.py deep-search "<topic>" -o temp_read/<name>.md` or `gemini_deep_research.py`) with dynamic shared fleet negotiation, or spawn a dedicated search subagent (`TypeName='self'`) to run `search_engine.py search "<query>" --engine parallel` (Tavily + Firecrawl parallel).
- **Intermediate Python Wrapper Scripts for CLI Tools (`run_argon_query.py`)**: When commanded to consult Argon or run Deep Research, agents over-think shell string escaping, spend 16+ seconds deliberating, inspect CLI flags via `--help`, and create unnecessary intermediate Python wrapper scripts (e.g. `run_argon_query.py +35 lines`) to execute `consult_argon.py`. This wastes 2-3 turns, slows execution by 30+ seconds, and clogs `temp_read/`. Agents must execute `consult_argon.py` directly on Turn 1 via `run_command`. For multi-line prompts, use `--prompt-file temp_read/prompt.md` to achieve 100% shell-safe execution with zero wrapper scripts.
- **Residual Baseline Counter Desync in Angular Apps (`gemini_brain_driver.py`)**: When creating fresh chat sessions, Angular DOM removal takes 600-1200ms. Evaluating `document.querySelectorAll('model-response').length` immediately after "New chat" yields `1`, causing polling `count <= baseline` to stay True (`1 <= 1`) and stall for 300s despite the response being rendered. For fresh sessions (`turns == 0`), `baseline` must be strictly hardcoded to `0`.
- **Angular CDK Overlay `scrollIntoView()` Premature Dismissal**: Calling `scrollIntoView()` on elements inside Angular Material CDK overlays triggers `CloseScrollStrategy`, instantly closing and detaching popovers/menus before click events can be dispatched. Never call `scrollIntoView()` on overlay trigger buttons or menu items; use direct `.click()` or CDP input events.
- **Two-Tier Cascading Tool Drawers & Deep Research Decoupling**: Gemini's `Upload & tools (+)` button cascades into a secondary `More tools` submenu for `Deep research`. Automated drivers must handle this 2-level hierarchy and decouple `actual_deep_research` from caller flags so that failed toggles fall back gracefully to standard Argon completion rather than waiting 300s for a missing plan card.
- **NumPy Ndarray Truth Value Evaluation Trap (`ValueError: The truth value of an array with more than one element is ambiguous`)**: In Pandas DataFrames loaded from Parquet, nested columns containing lists or arrays are parsed as `numpy.ndarray`. Evaluating `if arr:` in Python calls `__bool__()`, which NumPy rejects with `ValueError: The truth value of an array with more than one element is ambiguous. Use a.any() or a.all()`. This silently aborts shard loading loops. ALWAYS use explicit length guards: `(len(arr) > 0) if hasattr(arr, '__len__') else bool(arr)`.
- **Catastrophic Syntax Destruction via Attention Projection Refusal Abliteration**: Projecting the orthogonal refusal projector $P_\perp = I - r r^T$ onto `self_attn.o_proj` perturbs multi-head attention routing and positional coherence, causing entropy collapse and generating corrupt multilingual unicode, broken LaTeX fractions, and raw code snippets during evaluation.
